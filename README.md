# X All Photo Grid

Xの複数画像投稿を、番号付き・3列のサムネイル一覧で表示する非公式ブラウザ拡張機能です。

6枚で省略される画像一覧を、7〜20枚の静止画像投稿で展開します。
XColumnで動作確認済みです。Chrome・Edgeに読み込めるManifest V3形式ですが、単体ブラウザでの動作は未検証です。
バージョン: **0.2.1**

## 表示例

8枚なら次のように並びます。20枚なら7段で、最後の段が2枚になります。

```text
┌───┬───┬───┐
│ 1 │ 2 │ 3 │
├───┼───┼───┤
│ 4 │ 5 │ 6 │
├───┼───┼───┘
│ 7 │ 8 │
└───┴───┘
```

- 画像全体が見えるように表示します。縦横比により余白が出ます。
- 左下に投稿内での画像の順番を表示します。
- サムネイルをクリックすると、対応する画像ページを別タブで開きます。
  XColumnの設定によって実際の開き先が変わる場合があります。

## XColumnへの導入

1. このリポジトリの **Code → Download ZIP** からダウンロードし、ZIPを展開します。
2. XColumnで **ツール → 拡張機能の管理 → フォルダから追加** を開きます。
3. `manifest.json` が入っているフォルダを選びます。
4. この拡張機能を有効にして、XColumnを再起動します。
5. 対象の投稿を開き直します。

展開したフォルダは削除・移動せずに保存してください。
旧版がある場合は旧版を無効にし、現行版だけを有効にしてください。
Control Panel for Twitterの設定変更は必須ではありません。

## 対応範囲と制限

- 対象: **7〜20枚の静止画像だけを含む投稿**。
- 元の画面に6枚以上の画像リンクが存在する、Xの標準的な投稿HTMLが前提です。
- 動画が混在する投稿、6枚以下の投稿、画像の拡大ダイアログは変更しません。
- XColumn上で動作確認済みですが、すべての環境での動作を保証するものではありません。
- 単体のChromeやEdge、その他の拡張機能との組み合わせは未検証です。
- Xの非公開の内部データ構造に依存するため、X側の変更で動作しなくなる場合があります。
- 一覧化に伴い、画像の読み込み量と投稿の表示高さが増えます。

## データの扱い

拡張は、表示中の投稿に結びつくページ内のReactデータから、投稿IDと画像URLを読み取ります。
それらはページ内のメモリで一時的に保持し、対応するサムネイルの表示に使用します。

- 独自の解析・収集サーバーへの送信はありません。
- 投稿の画像情報を得るための追加API呼び出しは行いません。
- Cookie、パスワード、認証トークン、閲覧履歴を取得する処理はありません。
- データの永続保存は行いません。
- サムネイル画像は `pbs.twimg.com` から読み込みます。
- `fetch` や `XMLHttpRequest` などの通信処理を書き換えません。
- データを取得できない場合は、元の画像表示を残します。

## 問題が起きたら

まずこの拡張を無効にし、カラムの再読み込み、またはXColumnの再起動を行ってください。
報告にはXColumn・拡張のバージョン、症状、他の拡張の有無を添えてください。
非公開投稿、個人情報、認証情報を含むスクリーンショットやログは公開しないでください。

## 開発・テスト

実行時の外部ライブラリ、ビルド作業は不要です。
Node.jsが使える環境では、次のコマンドで検証できます。パッケージのインストールは不要です。

```sh
npm test
```

テストは模擬DOMと模擬Reactデータを使用します。通信関数を変更しないこと、
8枚・20枚の生成、番号の順序、固定サイズ枠の外への配置、二重追加防止、再描画時の復元を確認します。
ブラウザの実際のレイアウトやXの現在の内部構造を再現するテストではありません。
